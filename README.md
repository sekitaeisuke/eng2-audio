# eng2-audio

中2英語ワークブック「eng2_full」のリスニング音声（GitHub Pages 配信）。

- 691クリップ × 通常 / ゆっくり(0.75倍) = 1382ファイル
- 音声: Google Cloud TTS (Neural2, en-US-Neural2-F)
- 配信URL: `https://sekitaeisuke.github.io/eng2-audio/<clip-id>.mp3`
- 各PDFのQRコードがこのURLを指す（ビルド時 `ENG2_AUDIO_BASE_URL` で埋め込み）

姉妹リポジトリ: [eng1-audio](https://github.com/sekitaeisuke/eng1-audio) / [eng3-audio](https://github.com/sekitaeisuke/eng3-audio)
